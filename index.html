RDM-7 Dash Recovery Flasher

Reflash your dashboard over USB when over-the-air updates fail.

Firmware v1.4.5

Firmware Update

Replaces the firmware over USB. Keeps your Wi-Fi credentials, layouts, and all settings intact.

Your browser doesn't support USB flashing.
Use the latest Chrome or Edge on a desktop computer.
Recommended. Use this if Wi-Fi OTA updates aren't working. When the "Erase device?" dialog appears, leave the box unchecked and click Next — that's what preserves your settings. Takes about 60 seconds.

Full Recovery Flash

Reinstalls the bootloader, partition table, and firmware. Use if a regular Firmware Update doesn't fix the problem, or if the dashboard is stuck in a boot loop.

To do a full factory reset: when the "Erase device?" dialog appears, check the box and click Next. All Wi-Fi credentials, layouts, images, and settings will be erased and you'll need to redo first-run setup.

To repair without losing data: leave the box unchecked and click Next. The boot chain gets rewritten but settings are kept. Try this first.

How to flash

  1. Open this page in Chrome or Edge On a desktop or laptop computer. Safari, Firefox, and mobile browsers won't work — USB flashing needs the Web Serial API.
  2. Flip the UART switch on the back of the device to UART1 Required for USB communication. The dashboard ships in UART2 mode (used by the indicator outputs). If you skip this, the device won't appear in the serial port list.
  3. Connect the dashboard with a USB-C cable Use a quality data cable — many charge-only cables won't pass USB data and the device won't appear.
  4. Click "Connect" above A pop-up will list available serial ports. Pick the one labelled "CH341" / "USB-SERIAL CH341A" (or "USB JTAG/serial debug unit" if the dash boots into UART2 mode).
  5. Click "Install RDM-7 Dash Firmware" An "Erase device?" dialog will appear with a checkbox. For Firmware Update, leave it unchecked. For a full factory reset via Full Recovery, check it. Then click Next.
  6. Wait for the flash to complete Takes about 60 seconds. Don't unplug the cable until you see "Installation complete".
  7. Flip the UART switch back to UART2 Unplug USB first, flip the switch, then power the dashboard back on. If you leave it on UART1, the indicator outputs (turn signals, warning lights, etc.) won't work.
  8. Done The dashboard boots into the new firmware. Set up Wi-Fi from the on-screen wizard if needed.

Troubleshooting

Nothing happens when I click Connect

Make sure you're on Chrome or Edge desktop. Safari, Firefox, mobile browsers, and tablets don't support USB flashing. Also check the cable — try a different one if the device doesn't appear in the port list.

Do I need to install a USB driver?

The RDM-7 Dash uses a CH341 USB-to-serial chip. Driver requirements:

  • Windows 11: usually auto-installs from Windows Update — try plugging in first, only grab the driver if Device Manager shows an unknown device.
  • Windows 10 / 8 / 7: driver is required. Download CH341SER from WCH → run the installer → reboot if asked.
  • macOS: driver is required on all versions. Download CH34xSER for macOS → install the .pkg → approve the system extension in System Settings → Privacy & Security if prompted.
  • Linux: the kernel ships the ch341 module by default — works out of the box.
  • ChromeOS: works out of the box.

If the page can't find the device after installing the driver, fully unplug the USB cable, plug it back in, then refresh this page.

The device isn't in the port list

Three things to check, in order:

  1. The UART switch on the back of the dashboard must be set to UART1 — UART2 disconnects USB entirely so nothing will show up.
  2. Install the CH341 driver (see the entry above) if you're on Windows or macOS and haven't already. Without it, Device Manager shows an unknown device with a yellow exclamation.
  3. Try a different USB cable — many cables are charge-only and don't pass data. Try a different USB port too if you have a hub in the chain.
Indicators / turn signals don't work after flashing

The UART switch on the back of the device is still on UART1 (USB mode). Power off, flip the switch to UART2, and power back on. The indicator outputs share the UART2 pins, so they're disabled while the switch is on UART1.

Flashing fails partway through

Unplug the device, plug it back in, refresh this page, and try again. If it keeps failing, try a shorter or higher-quality USB cable — long cables can cause data errors during the flash.

After flashing, the screen is blank or stuck on boot

Most likely the "Erase device?" checkbox was left unchecked while doing Firmware Update on a device that needs a fuller rewrite. Try Full Recovery Flash with the box unchecked — that rewrites the bootloader and partition table while keeping settings. If that fails, try Full Recovery Flash with the box checked for a complete factory reset.

"invalid header: 0xffffffff" repeating in the log

The bootloader can't find a valid app image. Run Full Recovery Flash — leave the "Erase device?" box unchecked to rewrite the boot chain while keeping your settings, or check it for a clean factory state.

Will Firmware Update erase my settings, Wi-Fi, or layouts?

No. The Firmware Update mode writes only the firmware image and the OTA selector — it doesn't touch the NVS partition (Wi-Fi credentials, settings) or LittleFS (layouts, images, fonts). After flashing, the dashboard reboots into the new firmware and reconnects to your Wi-Fi automatically.

When should I use Full Recovery instead?

Only if a normal Firmware Update doesn't fix the problem — for example, the dashboard is stuck in a boot loop, the screen stays black after power-on, or the device won't appear in the serial port list after flashing. Full Recovery wipes the entire flash and reinstalls everything from scratch, so you'll lose all settings and saved data.
