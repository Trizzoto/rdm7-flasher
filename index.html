RDM-7 Dash Recovery Flasher

Reflash your dashboard over USB when over-the-air updates fail.

Firmware v1.1.9

Flash your device

Your browser doesn't support USB flashing.
Use the latest Chrome or Edge on a desktop computer.
When to use this: only if your dashboard is stuck on an old version and Wi-Fi updates aren't working. For normal updates, use the dashboard's built-in Wi-Fi update button.

How to flash

  1. Open this page in Chrome or Edge On a desktop or laptop computer. Safari, Firefox, and mobile browsers won't work — USB flashing needs the Web Serial API.
  2. Connect the dashboard with a USB-C cable Use a quality data cable — many charge-only cables won't pass USB data and the device won't appear.
  3. Click "Connect" above A pop-up will list available serial ports. Pick the one that looks like "USB JTAG/serial debug unit" or "CP210x"/"CH340" depending on your board.
  4. Click "Install RDM-7 Dash Firmware" The flash takes about 60 seconds. Don't unplug the cable until you see "Installation complete".
  5. Done The dashboard reboots automatically into the new firmware. Set up Wi-Fi from the on-screen wizard if needed.

Troubleshooting

Nothing happens when I click Connect

Make sure you're on Chrome or Edge desktop. Safari, Firefox, mobile browsers, and tablets don't support USB flashing. Also check the cable — try a different one if the device doesn't appear in the port list.

The device isn't in the port list

On Windows, install the CP210x or CH340 USB-serial driver if Device Manager shows an unknown device. On macOS and Linux, the device should appear without drivers. If it still doesn't show up, try a different USB port or cable.

Flashing fails partway through

Unplug the device, plug it back in, refresh this page, and try again. If it keeps failing, try a shorter or higher-quality USB cable — long cables can cause data errors during the flash.

After flashing, the screen is blank or stuck on boot

Hold the BOOT button (if your board has one) while reconnecting USB, then re-run the flash. This forces the chip into download mode for a clean install.

Will this erase my settings and layouts?

No. This flasher preserves the NVS and LittleFS partitions, so your Wi-Fi credentials, layouts, and saved settings stay intact. Only the firmware itself is replaced.
